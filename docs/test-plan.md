# AI Chatbot Test Plan


## 1. Project Overview

This project is an AI chatbot application created for QA testing practice.

The purpose is to validate:
- User authentication flow
- Chat functionality
- Input validation
- Security aspects
- Application reliability


## 2. Testing Scope


### In Scope

- Login functionality
- Chat messaging
- Input validation
- Error handling
- Security testing
- UI behavior


### Out of Scope

- Payment systems
- Mobile application
- Third-party integrations


## 3. Testing Types

### Manual Testing

- Functional testing
- Exploratory testing
- Regression testing


### Automation Testing

Tools:
- Playwright
- JavaScript


### Security Testing

Scenarios:
- XSS testing
- Input sanitization
- Invalid data handling


## 4. Test Environment

Environment:
- Localhost

Browser:
- Google Chrome

Operating System:
- Windows


## 5. Defect Management

Bug reports include:

- Bug ID
- Title
- Severity
- Priority
- Steps to reproduce
- Expected result
- Actual result
- Status


## 6. Entry Criteria

Testing starts when:

- Application is running
- Main features are available


## 7. Exit Criteria

Testing is completed when:

- Critical bugs are fixed
- Test cases are executed
- Test results are documented
